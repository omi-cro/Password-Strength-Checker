# Password Strength Checker

This project checks the strength of a user-entered password and classifies it as Weak, Medium, or Strong.

## Rules Used
- Minimum length: 8 characters
- Uppercase letter
- Lowercase letter
- Digit
- Special character

## Language
- C (Console-based)

## How to Run
gcc password_checker.c
./a.out
